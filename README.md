# 海の見えるCafé T

海辺の架空カフェ「Café T」を想定した、店舗紹介サイトです。海を眺めながら過ごす時間をテーマに、飲食メニュー、時間帯ごとの過ごし方、店舗情報、アクセスを紹介しています。

## 作品概要

- 種別：架空カフェの店舗サイト
- 想定クライアント：海沿いでカフェを営む個人事業主・小規模店舗
- 想定する閲覧者：店の雰囲気やメニュー、営業時間、アクセスを来店前に確認したい人

## 制作目的

海を眺めながらコーヒーや食事を楽しめる店の特徴を、ビジュアルと文章で伝えることを目的にしました。朝・昼・夕暮れの過ごし方を示し、単なるメニュー紹介にとどまらず、来店時の体験を想像できる構成にしています。

## 使用技術

- HTML
- CSS
- JavaScript
- Vercel（公開）

## 主な機能・コンテンツ

- Concept：海辺で過ごす店のコンセプト紹介
- Menu：パンケーキ、フレンチトースト、チーズケーキ、ローストビーフプレートなどの紹介
- ドリンクメニュー：コーヒー、ハーブティー、ワイン、クラフトビールの表示
- Moments：Morning、Lunch、Sunsetの時間帯別の過ごし方紹介
- Gallery：料理と空間のビジュアル紹介
- Information：営業時間、定休日、所在地、席数、テラス席、駐車場、支払い方法
- Access：海沿いの道から店舗までのアクセス案内
- スマートフォンでの閲覧を想定したメニュー開閉とレイアウト

## 工夫した点

- ファーストビューで「海を眺めて、ほどける時間」というサイトのテーマを明確にしました。
- Concept、Menu、Moments、Gallery、Information、Accessの順に、店の魅力から来店情報まで流れを作りました。
- Morning・Lunch・Sunsetに分け、利用シーンを具体的に想像しやすくしました。
- 料理名、説明、価格を整理して、メニューを比較しやすくしています。
- 画像には内容が分かる代替テキストを設定し、写真中心のページでも情報を読み取れるようにしています。
